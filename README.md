# Frostpunk Mod

A hardcore winter survival mod for Minecraft 1.21.1 inspired by Frostpunk.

## Features (In Development)

### Core Mechanics
- **Extreme Cold System**: Continuous frost damage in cold biomes without heat sources
- **Heat Management**: Strategic placement of heat sources to create safe zones
- **Winter Survival**: Harsh penalties for being unprepared

### Content
- **Heat Source Blocks**: Furnaces, heaters, and heat beacons that emit warmth
- **Winter Armor**: Specialized winter clothing for frost resistance
- **Cold Biomes**: Enhanced hostile snowy environments
- **New Materials**: Winter-themed building blocks

## Installation

1. Install NeoForge 1.21.1
2. Download the mod jar from releases
3. Place in `mods` folder
4. Launch Minecraft

## Development

```bash
./gradlew build
```

## Hardcore Features

- No easy mode - survival is challenging
- Permadeath-friendly design
- Resource scarcity in cold regions
- Unforgiving environmental mechanics
